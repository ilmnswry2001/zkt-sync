# وكيل مزامنة ZKTeco

يرسل الوكيل سجلات جهاز ZKTeco إلى واجهة `/api/public/zkteco-sync` كل دقيقة. يعمل على حاسوب يستطيع الوصول إلى الجهاز عبر الشبكة المحلية وإلى النظام عبر HTTPS.

## الإعداد

1. من صفحة **الأجهزة** في النظام، أضف الرقم التسلسلي المطابق للجهاز وأنشئ مفتاح الربط.
2. نزّل `zkteco_sync_agent.py` وملف `agent_config.ini` من الصفحة. ملف الإعدادات يحتوي المفتاح السري؛ احتفظ به على الحاسوب ولا تشاركه.
3. ثبّت Python 3.10 أو أحدث، ثم ثبّت الاعتماديات:

```sh
python -m pip install -r requirements.txt
```

4. ضع السكريبت وملف الإعدادات في المجلد نفسه. شغّله للاختبار:

```sh
python zkteco_sync_agent.py
```

يمكن تمرير مسار إعدادات مختلف كوسيط أول. افتراضياً يتصل الوكيل بالمنفذ TCP 4370، ويقرأ سجلات الجهاز، ويحفظ الحركات غير المرسلة في `sync_state.json`. لا يُحذف الطابور إلا بعد استلام HTTP 200 من النظام. تُحفظ حالة الوكيل محلياً بعد كل محاولة.

## تشغيل مستمر

على Windows، أنشئ مهمة في Task Scheduler لتشغيل `python.exe` مع مسار `zkteco_sync_agent.py` عند بدء الحاسوب، وفعّل إعادة التشغيل عند الفشل. على Linux يمكن تشغيله تحت systemd مع `Restart=always`.

إذا تغيّر مفتاح الجهاز أو سُحب، أنشئ مفتاحاً جديداً ونزّل ملف إعدادات جديداً. المفتاح القديم يتوقف فور تدويره.
